# Contrats communs

Ces documents sont les emplacements de travail pour les décisions communes de la semaine 1. L’équipe complète et révise les contrats avant que les modules ne dépendent de leurs détails. Aucun schéma ou endpoint n’est imposé ici.

- [Modèles de données](MODELES_DONNEES.md) : entités, champs, relations, identifiants et règles d’isolation.
- [API](API.md) : endpoints, formats d’échange, erreurs, authentification et conventions de version.
- [Statuts de facture](STATUTS_FACTURE.md) : états, transitions, acteur autorisé et résultat de chaque transition.
- [Permissions](PERMISSIONS.md) : rôles, actions, périmètres d’entreprise et vérifications requises.

Une modification touchant plusieurs modules suit la procédure de changement de contrat décrite dans [CONTRIBUTING.md](../../CONTRIBUTING.md).
