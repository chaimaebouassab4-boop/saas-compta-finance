# API — à définir en semaine 1

Décider ensemble :

- endpoints et module propriétaire ;
- méthode, chemin, entrée, réponse et erreurs ;
- formats d’échange et conventions de nommage ;
- authentification, rôle et contexte d’entreprise requis ;
- pagination, idempotence, versionnement et opérations asynchrones si utiles ;
- exemples fictifs et stratégie temporaire de mocks.

Ne pas figer de technologie avant la décision de l’équipe.
