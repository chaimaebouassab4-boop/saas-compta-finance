# Tests de sécurité croisés entre entreprises

Emplacement des tests vérifiant qu’un utilisateur d’une entreprise ne peut pas lire ou modifier les données d’une autre entreprise. Les scénarios et l’outillage restent à définir avec les contrats et la stack.

Répartition des tests croisés : membre 1 teste le module du membre 2 ; membre 2 teste le module du membre 3 ; membre 3 teste le module du membre 1. N’utiliser que des données fictives.
